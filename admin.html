          Published

          Family password for writers

          Anyone with this password can open the Write an article page and send an article for your review. It unlocks a separate GitHub key that can only create submissions, so it cannot change anything on the site.

          Setting a new password replaces the old one, so anyone using the old password will need the new one.

          Download a backup

          Saves the family tree exactly as it is right now — every person, their details, and how they connect — as one file on your device. Keep these safe; each one is a full snapshot you can return to.

          Restore from a backup

          Replaces the entire live tree with whatever is in the file you choose — including undoing any edits made since that backup was taken. There's no undo for this beyond restoring an even older backup, so be sure before you confirm.
