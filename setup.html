Superuser setup

You only do this once — to create your own superuser login. After that, you add and remove everyone else's passwords from inside the Edit page itself, no tokens involved.

This page isn't linked from the site's navigation on purpose. Keep the URL to yourself — you'll only need it this one time.
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Scope it to only this one repository, and grant only the "Contents: Read and write" permission. Nothing else.
  3. Copy the token it gives you, paste it below, choose your own name and a password, and click Generate.
  4. Paste the result into data/access.json (inside the editors array) and commit it.
  5. You're done — go to admin.html and sign in with that password. You'll see a "Manage editors" tab where you can add everyone else, each with their own password, no tokens needed from here on.
